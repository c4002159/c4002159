## 🔥 Open Source & Research Work · 开源二次开发与研究项目

| 项目 | 上游 | 我做的部分 |
|---|---|---|
| [**SLM-eva**](https://github.com/c4002159/SLM-eva)（MSc 论文） | 无，原创研究；使用 lm-evaluation-harness、Ollama、PEFT 和 Glaive 工具调用数据 | **评测**：在一台笔记本（RTX 4050）上评测 5 个 0.5B–3.8B 小模型（Qwen2.5-0.5B、TinyLlama-1.1B、Qwen2-1.5B、Llama-3.2-3B、Phi-3-mini）。三套测试集：通用能力基准（MMLU / ARC / HellaSwag）、自建 50 条运行负载集（Alpaca、GSM8K、OASST1、CNN/DailyMail 按长度分层）、自建 33 条工具调用集（25 条应调用 + 8 条不应调用）。3 种负载 × 3 次重复共 2,250 次请求，测延迟、吞吐、内存和每 token 能耗，Friedman + Wilcoxon 检验。<br>**微调**：对工具调用最可靠的 Llama-3.2-3B 做 LoRA（r=16，α=32，作用于 q/k/v/o，lr 2e-4，5 epoch），训练集三轮迭代 500 → 241 → 229 条（Glaive tool_call 150 条 + 自行整理的 no_call 数据）。“不该调用时不调用”的正确率 0% → 100%，总体 72.7% → 78.8%；代价是工具选择 100% → 70%、复杂参数 96% → 60%（测试集仅 33 条，只说明有取舍） |
| [**ai-job**](https://github.com/c4002159/ai-job) | BossHunter（PolyForm Noncommercial） | 前程无忧 / 猎聘页面确认式一键投递；猎聘附件简历读取预览 → AI 标签 → 按岗位匹配选简历，没有合适的自动降级打招呼；关键词分档预算与自动升降档；跨平台公司去重；匹配度 / 活跃度双指标。22 次提交，约 +9,200 行，新增约 190 个测试 |
| [**open_deep_research**](https://github.com/c4002159/open_deep_research)（企业数据分析 Agent） | LangChain open_deep_research（MIT） | 沙箱执行与只读 SQL；超时 / 重试 / 熔断 / 模型降级；涉密查询人工审批；61 条用例的评测集与基线；带幂等和限流的异步 HTTP 服务；“退款”工作流里 Agent 只能提交申请，批准由有权限的人签字 |
| [**short-link**](https://github.com/c4002159/short-link)（Java） | nageoffer/shortlink（课程作业） | Caffeine + Redis 两级缓存；Redis Pub/Sub 本地缓存失效广播；Lua 脚本实现点击上限；k6 压测与对照数据 |

## 我怎么写这些仓库 · How I write my repos

- 上游是谁、我改了什么，写在 README 开头
- 每个能力都有测试；碰真实账号 / 真实数据的功能，先只读观察，再小范围验证
- 写清楚没验证过的部分和已知的边界（比如上面微调结果的样本量）
